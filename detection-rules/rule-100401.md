---

## 1. Detection Objective

The objective of Rule 100401 was to detect when the Windows Security audit log is cleared.

Clearing security logs can be associated with defense evasion because an attacker may attempt to remove evidence of activity from the endpoint.

The rule was therefore designed to identify Windows Security Event ID `1102`.

---

## 2. MITRE ATT&CK Technique

**T1070.001 — Clear Windows Event Logs**

**Tactic:** Defense Evasion

The technique focuses on the clearing of Windows event logs to remove or obscure evidence of activity.
