# Evidence

This directory contains screenshots and supporting evidence from the Detection Engineering & Alert Triage project.

The evidence demonstrates the practical implementation and validation of the Wazuh detection engineering workflow, including endpoint monitoring and successfully generated security alerts.

## Available Evidence

### 1. Windows Endpoint Dashboard

The Windows endpoint dashboard provides evidence of the monitored Windows security environment used during the detection engineering exercises.

**File:** `windows-endpoint-dashboard.png`

### 2. Rule 100401 — Clear Windows Event Logs

This screenshot shows a Wazuh alert generated for the Clear Windows Event Logs detection.

**MITRE ATT&CK:** T1070.001 — Indicator Removal: Clear Windows Event Logs

**Wazuh Rule:** 100401

The alert includes Windows Security Event ID 1102, indicating that the security audit log was cleared.

**File:** `rule-100401-cleared-logs.png`

### 3. Rule 100402 — System Information Discovery

This screenshot shows a Wazuh alert generated when `systeminfo.exe` was executed on the Windows endpoint.

**MITRE ATT&CK:** T1082 — System Information Discovery

**Wazuh Rule:** 100402

The evidence demonstrates successful detection of system information discovery activity.

**File:** `rule-100402-systeminfo.png`

### 4. Rule 100403 — System Owner/User Discovery

This screenshot shows a Wazuh alert generated by `whoami.exe` execution.

**MITRE ATT&CK:** T1033 — System Owner/User Discovery

**Wazuh Rule:** 100403

The evidence demonstrates successful detection of user-account discovery activity.

**File:** `rule-100403-whoami.png`

## Defender-Prevented Scenarios

Two additional detection scenarios were tested but were prevented by Windows Defender before the expected behavior could fully execute:

- **Rule 100404** — T1003.001: OS Credential Dumping: LSASS
- **Rule 100405** — T1105: Ingress Tool Transfer

No screenshots are included for these two scenarios because screenshot evidence was not captured during the original testing.

The scenarios and their results are documented in the project documentation.
